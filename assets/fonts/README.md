# 폰트

- Archivo-Variable.ttf: Google Fonts 공식 저장소의 Archivo. 라이선스는 Archivo-OFL.txt.
- MabryPro-Regular.ttf / MixtaEssSharp-Italic.otf: 사용자 PC에 설치된 파일을 복사해 styles/fonts.css에서 직접 연결했습니다. Mixta는 피그마와 같은 Fontspring DEMO 파일입니다.
- Jam Grotesque Medium: 아직 파일을 찾지 못했습니다. 설치된 폰트 인식 설정을 유지합니다.
- 원본 웹폰트를 확보하면 이 폴더에 저장한 뒤 해당 @font-face의 src에 url()을 연결하세요.
- NotoSansKR-Variable.ttf: 한글용 대체 폰트. Google Fonts 공식 파일이며 라이선스는 NotoSansKR-OFL.txt입니다. 피그마는 한글에도 Mabry Pro를 지정하지만 실제 한글 대체 폰트 이름은 응답에 포함되지 않습니다. 모든 한글 자간은 -0.025em입니다.
