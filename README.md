# TWO SLASH FOUR · 1차 레이아웃

[피그마 원본](https://www.figma.com/design/IcgPzl4eMORbAIEqNpRCOS/?node-id=387-1098)을 바탕으로 만든 HTML / CSS / JavaScript 프로젝트입니다.

## 확인 방법
`index.html`을 브라우저로 바로 열면 됩니다. Node.js가 있으면 `npm run dev`로 실행하고 http://localhost:3000 에 접속하세요. 외부 패키지 설치는 필요 없습니다.

## 폴더
```text
index.html
design-tokens.md
styles/
  tokens.css
  global.css
scripts/
  main.js
  build.mjs
  serve.mjs
components/
  header/          # 헤더, 메뉴, 미리보기 팝업
  hero/            # 로고, 캠페인 콜라주, 쿠션
  new-products/    # 신제품 가로 스크롤
  best-products/   # 비대칭 제품 소개
  tutorials/       # 튜토리얼 가로 스크롤
  footer/          # 연락처, 사업자 정보, 로고
assets/
  images/         # 피그마 원본 이미지와 아이콘
  manifest.json   # 원본 에셋과 로컬 파일 매핑
```

각 컴포넌트 폴더에 HTML과 CSS를 두고, 동작이 있는 헤더와 튜토리얼에 JS를 둡니다. 컴포넌트 HTML 수정 후 `npm run build`를 실행하면 index.html에 반영됩니다. CSS와 JS 수정은 직접 반영됩니다. 브라우저에서 파일을 바로 열 수 있도록 index.html은 조립된 정적 HTML로 유지합니다. 전체 문서 틀은 `scripts/page-template.html`에서 수정합니다. PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd run build`, `npm.cmd run dev`를 사용하세요.

## 구현 범위
- 히어로, 이미지 콜라주, NEW / BEST, 튜토리얼, 푸터 전체 1차 배치.
- 메뉴 열기/닫기, 섹션 이동, 튜토리얼 이전/다음 스크롤.
- 모바일 폭 대응, 키보드 포커스, 모션 감소 설정.
- 피그마 원본 에셋 로컬 저장.

## 인터랙션
- 참고: [Cue](https://www.cuewigs.com/). 공개 동작 설정을 확인하고 현재 디자인에 맞게 순수 JavaScript/CSS로 구현했습니다.
- 히어로: 데스크톱에서 로고 앞 큰 사진이 스크롤에 따라 축소되며 콜라주 가운데 사진 자리에 도착합니다. 도착 직전 가운데 사진으로 부드럽게 전환하고, 역스크롤 시 되돌아갑니다. 가운데 사진의 실제 좌표를 사용해 리사이즈에도 배치를 맞춥니다.
- Cue 히어로 타임라인에 맞춰 220svh의 전환 구간을 추가했습니다. 화면을 고정하고 사진 프레임이 가운데 자리로 이동하며 작아집니다(전체 구간의 42.5%). 사진 내부 확대 효과는 없습니다. 이후 왼쪽 이미지는 아래에서, 오른쪽 이미지는 위에서 진입합니다(45%부터 끝까지). 로고는 위로 빠지고, 전환이 끝나면 고정을 해제해 쿠션 소개로 이어집니다. 서로 다른 디자인과 이미지 비율에 맞춰 배치는 조정했습니다.
- 제목과 이미지: 화면 진입 시 단어별/카드별 순차 등장.
- MEET THE NEW…: Cue의 큰 문구처럼 각 줄이 화면의 60% 높이에 들어오면 아래에서 위로 드러납니다. 원래 흰 배경과 검정/블루 강조는 유지하며, 한 번 등장한 줄은 표시 상태를 유지합니다.
- BEST: 텍스트는 인터랙션 없이 바로 표시합니다. 제품 이미지의 아래에서 위로 가림막이 걷히는 효과는 유지합니다.
- MEET / THE best 제목에만 줄별 아래에서 위로 드러나는 효과를 적용합니다. 제품 제목, 한글 설명과 캡션은 정적으로 유지합니다.
- BEST 배너: 이미지 가림막 등장과 가벼운 세로 이동, 좌측 두 줄과 우측 문구가 스크롤에 따라 안쪽으로 이동합니다. 이 배너 문구만 별도 인터랙션을 적용하고 제품 제목/설명은 정적으로 유지합니다. 이미지 확대는 없습니다.
- 쿠션 설명: 영문 제목과 한글 본문이 스크롤 진행에 따라 단어 순서대로 연한 회색에서 #111111로 바뀝니다. 배지는 유지하고, 역스크롤하면 색이 되돌아갑니다. 모든 한글 자간은 -2.5%(-0.025em)입니다.
- 쿠션 제목: Cue의 text-to-center 방식으로 new와 SATIN CUSHION은 오른쪽에서, ANGELIC과 이미지는 왼쪽에서 스크롤에 따라 가운데로 모입니다. 줄 간격도 넓게 시작해 피그마의 22px 간격으로 정돈됩니다. 역스크롤 시 다시 펼쳐지며 모바일/모션 감소 설정에서는 최종 배치를 유지합니다.
- NEW: 901px 이상에서 영역을 고정하고 세로 스크롤을 제품 가로 이동에 연결. 방향키와 Home/End로 이동 가능. 모바일은 직접 스와이프.
- 헤더: 내릴 때 숨김, 올릴 때 표시. 메뉴는 전체 화면 전환, Escape 닫기, 포커스 순환과 배경 스크롤 잠금.
- 튜토리얼: 마우스 드래그, 터치 스와이프와 이전/다음 버튼.
- 튜토리얼 갤러리: 데스크톱 세로 스크롤을 가로 이동으로 연결합니다. 스크롤바와 이전/다음 화살표는 숨겼으며, 마우스 드래그와 방향키/Home/End는 유지합니다. 모바일에서는 직접 스와이프합니다. 페이지와 모든 영역의 스크롤바도 숨겼습니다.
- 튜토리얼 제목: con1 쿠션 제목과 동일하게 TUTORIALS는 오른쪽, FOR와 이미지는 왼쪽에서 가운데로 모이며 줄 간격이 좁혀집니다. 모바일과 모션 감소 설정에서는 최종 배치를 유지합니다.
- 모바일에서는 히어로의 사진 이동/축소와 양옆 이미지 진입만 PC처럼 유지합니다. 그 외 텍스트·이미지 등장, 글자색 전환, 배너 이동, 호버 확대와 헤더 숨김은 해제합니다. 메뉴와 튜토리얼 직접 스와이프는 유지합니다.
- 설정: 시스템 모션 감소 사용 시 고정 스크롤과 등장 애니메이션 해제.
- 파일: `scripts/motion.js`, `styles/motion.css`. 기존 컴포넌트 JS에 메뉴/드래그 동작을 추가했습니다.
- 브라우저 검사 통과: 메뉴 열기/Escape 닫기, 배경 잠금 해제, 세로→가로 스크롤 연결, 모바일 화면 넘침, 모션 감소 설정.
